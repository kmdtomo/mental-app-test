# AIプロンプト最適化 - 感情分析強化版

## 📊 改善の概要

ユーザーの音声から文字起こし・感情分析を行った後、AIがより適切に本音を引き出せるよう、プロンプトを大幅に改善しました。

---

## 🎯 改善のポイント

### **1. VAD値の削除 → 感情ラベルのみに**

**改善前:**
```
セグメント1: "今日はサッカーの試合がありました..."
→ 穏やか・リラックス (覚醒度: 3.95, 快度: 4.15, 優位性: 4.02)
```

**改善後:**
```
セグメント1: "今日はサッカーの試合がありました..."
→ 感情: 穏やか・リラックス
```

**理由:**
- AIは数値（3.95が高いか低いか）を理解しにくい
- 感情ラベルだけで十分に意味が伝わる
- プロンプトがシンプルになり、AIが焦点を絞りやすい

---

### **2. 最もネガティブなセグメントを自動検出**

**機能:**
- Valence値が最も低いセグメントを特定
- ⚠️マークで強調表示

**例:**
```
セグメント2: "2対3で一歩及びませんでした。"
→ 感情: 悲しみ ⚠️【最も感情的に落ち込んでいる部分】
```

**効果:**
- AIが「どこに注目すべきか」を明確に理解
- 最も深掘りしやすい箇所を逃さない

---

### **3. 言葉と感情のギャップを自動検出**

**機能:**
- 前向きな言葉（「頑張る」「仕上げる」など）を検出
- ネガティブな感情ラベルと組み合わせてギャップを特定
- 💡マークで強調表示

**例:**
```
セグメント3: "戦術的に仕上げていきたいなと思いました。"
→ 感情: 中立 💡【言葉は前向きだが、声のトーンは沈んでいる】
```

**効果:**
- 「言葉では前向きだが、本当は落ち込んでいる」を検出
- 表面的な言葉の裏にある本音を引き出せる

---

### **4. 感情の変化を自動検出**

**機能:**
- セグメント間のValence変化量を計算
- 0.3以上の変化を「大きな変化」として検出
- 【感情の変化】セクションで明示

**例:**
```
【感情の変化】
セグメント2で大きな変化: 穏やか・リラックス → 悲しみ
```

**効果:**
- 感情の流れ（手応え→落胆→前向き）を把握
- 変化の瞬間に焦点を当てた質問ができる

---

### **5. 汎用的な応答戦略の提示**

**改善前:**
```
【指示】
セグメント別の感情分析を参考に、特に感情が表れている部分（中立以外）に注目して質問してください。
```

**改善後:**
```
【応答戦略の選択】
以下の3つの戦略から、最も適切なものを選んで応答してください：

1. **最も落ち込んだ瞬間に焦点（⚠️マーク）**
   - ⚠️マークがある場合、そのセグメントに焦点を当てる
   - 「〜と話された時、声のトーンが沈んでいました」と観察を伝える
   - 「その瞬間、どんな気持ちでしたか？」と具体的に聞く

2. **言葉と感情のギャップに注目（💡マーク）**
   - 💡マークがある場合、そのギャップを指摘する
   - 「〜と前向きに話されていましたが、声からは少し〜も感じました」
   - 「本当はどんな気持ちが一番強かったですか？」と本音を引く

3. **感情の変化に注目（【感情の変化】セクション）**
   - 感情の変化がある場合、その流れを指摘する
   - 「〜から〜に気持ちが変わったように感じました」
   - 「その変化の中で、どんな思いがありましたか？」と聞く

【重要】
- 共感→観察→質問の流れで2-3文で簡潔に
- 質問は1つに絞る
- 具体的で答えやすい質問をする
```

**効果:**
- 状況に応じて最適な戦略を選択
- パターンA/B/Cすべてに対応可能
- 具体的な例文でAIをガイド

## 📝 実際のプロンプト例

### **入力（文字起こし）:**
```
今日はサッカーの試合がありました。相手はカテゴリーが一つ上の、格上の相手でしたが、
試合内容的にはほとんどやれていったと思います。しかし、最後のところで力の差が出て、
2対3で一歩及びませんでした。いろいろ課題がある中で、あとリーグ戦がまで半年くらい
あるので、戦術的に仕上げていきたいなと思いました。
```

### **AIに送られるプロンプト:**
```
【ユーザーの発言】
"今日はサッカーの試合がありました。相手はカテゴリーが一つ上の、格上の相手でしたが、
試合内容的にはほとんどやれていったと思います。しかし、最後のところで力の差が出て、
2対3で一歩及びませんでした。いろいろ課題がある中で、あとリーグ戦がまで半年くらい
あるので、戦術的に仕上げていきたいなと思いました。"

【音声分析（セグメント別）】
セグメント1: "今日はサッカーの試合がありました。相手はカテゴリーが一つ上の、格上の相手でしたが、試合内容的にはほとんどやれていったと思います。"
→ 感情: 穏やか・リラックス

セグメント2: "しかし、最後のところで力の差が出て、2対3で一歩及びませんでした。"
→ 感情: 悲しみ ⚠️【最も感情的に落ち込んでいる部分】

セグメント3: "いろいろ課題がある中で、あとリーグ戦がまで半年くらいあるので、戦術的に仕上げていきたいなと思いました。"
→ 感情: 中立 💡【言葉は前向きだが、声のトーンは沈んでいる】

【感情の変化】
セグメント2で大きな変化: 穏やか・リラックス → 悲しみ

【応答戦略の選択】
（戦略1/2/3の詳細...）
```

### **期待されるAI応答（パターンA）:**
```
格上の相手にほとんど互角に戦えたのは素晴らしいですね。
でも、「2対3で一歩及びませんでした」と話された時、
声のトーンがぐっと沈んでいたのが印象的でした。
その瞬間、どんな気持ちだったのか聞かせてもらえますか？
```

## 🔧 実装詳細

### **変更ファイル:**
- `app/api/ai-chat/route.ts`

### **追加関数:**
1. `detectPositiveWords()` - 前向きな言葉を検出
2. `formatSegmentDetails()` - セグメント情報を強化版フォーマット
   - 最もネガティブなセグメント検出
   - 感情の変化検出
   - 言葉と感情のギャップ検出

### **変更箇所:**
- システムプロンプト: 変更なし（既に良好）
- ユーザープロンプト: 大幅改善
  - VAD値削除
  - 感情ラベルのみ表示
  - ⚠️と💡マークで重要箇所を強調
  - 3つの応答戦略を提示
